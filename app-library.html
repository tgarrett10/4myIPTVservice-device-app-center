How to Update Apps Using Downloader
  1. Open Downloader on your streaming device. Select Favorites in the left menu, then open the saved 4MyIPTV Service Support Page.
  2. If it is not saved, return to the Downloader Home screen, enter access code 2732515, and select Go.
  3. On the support page, select Apps & Updates. Find the affected app and read its update date and specific installation directions.
  4. If an app is not working and a newer version is posted, first go to your device Settings > Apps, select the affected app, and choose Uninstall. Then return to this Updates page, select Download, and choose Install when prompted. For an app that is working normally, no update is generally needed. Read the app-specific notes before making changes.
  5. When installation finishes, select Done. In Downloader, select Delete, then confirm Delete to remove the downloaded installation file, not the installed app.
  6. Repeat as needed. Press Home on your remote to return to the device home screen, or Back to exit Downloader.

Best practice: If an app stops working and an updated version is listed here, we recommend uninstalling the old app through your device Settings, then downloading and installing the updated version. Some apps can install over an existing version, but a fresh installation is our preferred approach for apps that are not working. Check the update date and special instructions for each app. Uninstalling may erase favorites, settings, or logins, so save your login details first.

Third-party availability: If an app fails and there is no working update available, it may no longer be supported or available. 4MyIPTV Service cannot guarantee the continued operation of third-party apps.
