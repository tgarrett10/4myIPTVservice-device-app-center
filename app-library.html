How to Update Your Apps

Keep your streaming apps updated for the best viewing experience. Follow these instructions whenever an app update is available.

Step 1 — Open Downloader

  1. Open the Downloader app on your streaming device.
  2. Navigate to Favorites using the menu on the left.
  3. Select the 4MyIPTV Service Support Page.
  4. If the support page is not saved in Favorites, return to the Downloader Home screen, enter access code 2732515, and select Go to open the support page.

Step 2 — Find Your App Update

  1. On the Support Page, select Apps & Updates.
  2. Scroll to find the application you want to update.
  3. Read the information beneath the download button. This includes the latest update date and any special installation instructions.
  4. Select Download.

Step 3 — Download and Install

  1. Allow the installation file to download.
  2. Select Install when prompted.
  3. Once installation is complete, select Done to return to Downloader.

Step 4 — Delete the Installation File

  1. In Downloader, select Delete to remove the downloaded installation file.
  2. Select Delete again to confirm.

This frees up storage space without removing your installed application.

Step 5 — Finish Up

Repeat these steps for any additional app updates. When finished, press Home on your remote to return to your device’s home screen, or press Back to exit Downloader.

Important: App Update Best Practices

Not every app needs to be uninstalled before updating.

Some applications allow you to install a newer version directly over the existing version. Others may require you to uninstall the previous version first.

  • If your app is working properly: Follow the update instructions listed beneath that application’s download button. You may be able to install the update without removing the existing app.
  • If your app is not working correctly: A fresh installation is often a good troubleshooting option. Uninstall the existing application, then download and install the latest version.
  • Always check the update details: Review the latest update date, version information when available, and any special instructions listed beneath each application.

Please note: Uninstalling an application may erase saved settings, favorites, or login information. Make sure you have any necessary login credentials before removing an app.
